## How it is built

`entry.png` (1024×1024) is drawn entirely in code by `render.py` (Python + PIL) — flat vector-style scenes, no photos. Run it with:

```sh
python3 render.py
```

`main.py` is the grader entrypoint: it copies the pre-rendered `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (standard library only — the grader image has no PIL).
